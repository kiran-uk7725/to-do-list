📝 Simple To-Do List App
A lightweight, clean, and responsive To-Do List application built using vanilla web technologies. This project is perfect for keeping track of daily tasks with data persistence.

✨ Features
* Add Tasks: Quickly add new items to your list.
* Mark as Done: Cross out completed tasks to track your progress.
* Delete Tasks: Easily remove tasks you no longer need.
* Persistent Storage: Uses localStorage to save your data, so tasks stay saved even after refreshing the page.
* Responsive Design: Works smoothly on desktops, tablets, and smartphones.

🛠️ Tech Stack
- HTML5: Semantic structure for the layout.
- CSS3: Modern styling with clean layout aesthetics.
- JavaScript (ES6): DOM manipulation and localStorage integration.

📁 Project Structure
├── images/          # Images used in the project
├── index.html       # Application layout and structure
├── style.css        # UI styling and responsive layouts
└── script.js        # Core logic (add, delete, complete, and localStorage)

⚙️ How to Run Locally
1. Clone the repository:
git clone https://github.com/kiran-uk7725/to-do-list

2. Navigate into the project folder:
cd /to-do-list

3. Open index.html in your favorite web browser
